## Review fixes

Pass 2 now reads the rest of the export and compares its SHA-256 with pass 1's when the state
machine refuses an op (changes, views, ledgers, indexes), so a file rewritten in place between the
passes is NRV-E0813 and an unchanged export the state machine refuses stays NRV-E0807. The export
is opened with `O_NONBLOCK`, checked for a regular file on that descriptor, and then switched back
to blocking, so a FIFO with no writer is refused (NRV-E0810) instead of blocking the open; a
directory is again "is a directory". NRV-W0012's segment range is built from `trace_segments_max`
and a unit test covers the start at the bound (1023 segments exist, `.1024` is created). README's
trace bound is 1025 times `--trace-size-max`. `trace_interrupted` is unchanged: SIGSTOP would be sent
at the moment SIGTERM is, so it narrows nothing.
