# O12 — 2026-11-21

NervaOrg/nerva#12 (fixes #11): `test:integration`'s one-tick lookup bound failed on the loaded
Woodpecker box (median 6.6 to 17.4 ms; 2.1 ms alone). The test is unchanged. `ci/woodpecker_step.sh`
now takes a host-wide reader/writer lock first (`ci_box_lock`, `ci/cache.sh`): `locks/box.lock`
shared for every job, exclusive for `integration`, with `locks/turnstile.lock` so shared jobs cannot
starve the exclusive one; bounded by `CI_BOX_WAIT` (5400 s), NRV-E1245 on a timeout. New codes
NRV-E1245 and NRV-B1203 (docs/ERRORS.md). `ci/ci_test.sh` has a new block with real flock: shared
holders coexist, the exclusive holder excludes, a waiting exclusive holder keeps new shared ones out,
a timeout fails with its code. Not built before the lock (needs `ci/job.sh`, which #9 changes);
not run on the real box. Decision O12.
