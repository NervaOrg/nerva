# O4 — 2026-11-20

NervaOrg/nerva#4: CI on a self-hosted Woodpecker (ci.botpike.com) beside GitHub Actions. Jobs are
plain `ci/` scripts both engines call; Woodpecker steps run privileged (io_uring) as an
unprivileged `ci` user, share one Zig cache across jobs and branches, and split `check` into
`check-code` and `check-scripts`. Adds the Woodpecker and Forgejo bootstrap scripts (Forgejo
pull-mirrors every 5 minutes) and lets the sim-fleet yield CPU and IO to CI.
