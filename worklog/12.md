# PR 12 — 2026-11-22

NervaOrg/nerva#12 (fixes #11): `test:integration`'s one-tick lookup bound failed on the loaded
Woodpecker box (median 6.6 to 17.4 ms; 2.0 to 2.3 ms alone). The test is unchanged. Third version,
after reviews 6008872330 and 6012650944. `ci/cache.sh` now holds the whole flow
(`ci_step_job_in_box`, `ci_step_integration`, `ci_box_lock`, `ci_box_unlock`): short jobs take
`locks/box.lock` shared around their run; `integration` builds shared (`ci/job.sh integration-build`,
the new `zig build test:integration:build`) then runs its test exclusive. The turnstile
(`locks/turnstile.lock`) is held only while waiting. One budget per call (`CI_BOX_WAIT`, derived by
`ci_box_wait_default`: 7380 s with the defaults, 2 calls = 246 minutes at the very worst), run limit
`CI_INTEGRATION_RUN_MINUTES` 20. Only flock status 1 is NRV-E1245; other statuses are NRV-B1204.
Long jobs (`fuzz-long`, `vopr-long`, `jepsen`) take no lock. `build.zig` gets one additive step
(owner-authorised, UPSTREAM.md). `ci/ci_test.sh` tests the flow dynamically with stub jobs; five
mutants of `ci/cache.sh` are each caught. Measured here (4 cores, Debug): `test:integration:build` 49 s
cold, then `test:integration` 607 s with nothing recompiled, lookup median 2.0 ms: the exclusive window
is the test run. Not run on the real box. Decision O12.
