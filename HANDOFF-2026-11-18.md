## #476: import reads one export (P476, P476b; fixes #475, #481)

- One input descriptor serves both passes, so a file renamed over the path is not read; a file
  rewritten in place ends pass 2 with another SHA-256 than pass 1's: NRV-E0813.
- Pass 2 refuses before the state machine what pass 1 would refuse, or what goes beyond pass 1's
  counts. `refused_or_changed` (mirroring `corrupt_or_changed`) reads the rest of the export
  after a state-machine refusal: a digest different from `plan.origin` is ExportChanged
  (NRV-E0813), otherwise Refused (NRV-E0807).
- Main brought #489 (P489, the exclusive create's loser touches nothing, NRV-E0814). The merge
  keeps both: `command_import` takes the input file and `created`; `import_failed` maps
  ExportChanged to E0813 and PathAlreadyExists to E0814.
- An `--input` that is not a regular file (a pipe, `/dev/stdin`) is NRV-E0810: it is read twice.
